Feature Vector Search Private Service Connect automation Deploying an index with Private Service Connect automation is generally available ( GA ). You can set up a service connection policy so that you don't have to manually create a compute address and forwarding rule after each index deployment. For more information, see Set up Vector Search with Private Service Connect .
