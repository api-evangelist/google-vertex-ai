# Google Vertex AI GraphQL API

Google Vertex AI is a unified machine learning platform covering model training, deployment, AutoML, feature store, model registry, pipelines, experiments, and access to foundation models via Model Garden including Gemini, PaLM, and Imagen.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Google Vertex AI REST/gRPC API
**Documentation:** https://cloud.google.com/vertex-ai/docs/reference/rest
